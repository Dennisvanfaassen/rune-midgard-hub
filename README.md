# Rune Midgard Hub

Create a full Ragnarok Online guild website. The name of the guild is Rune Midgard. What i want you to do is build a full website for our community. Features that i want to implement are:
- Party Planner with the option to select your class, the creator can add a date, time, place etc. We need templates to select characters needed for the party (core needed characters) The maximum party size is 12 members in a party.
- Stat calculator for your own character
- Skill simulator for your own character
- Overview of all our members, which you can click on to see their stat and skill build like a profile. So you can see each others gear they want to farm. You must be able to select: 'i have this gear' or 'i still need this gear' so we can help hunting

You can use the data from the files i have sent you to build the calculators
